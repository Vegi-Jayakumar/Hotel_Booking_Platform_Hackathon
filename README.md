Hotel Booking Platform with Dynamic Pricing

domain: Hospitality

problem Statement: 
  Small Independent hotels lack access to the dynamic pricing tools that large chains use, so they either set a flat rate year-round (losing revenue during high demand) or manually adjust prices (error-prone and slow), missing opportunities to optimize occupancy and revenue.

Our Approach:
  As the target users are small independent hotels, so, the proposed solution should be as simple as possible, which people with minimum tech exposure can access.
  We have developed a website with an Admin Page where these price increase multiples can be adjusted.
  We also integrated information dashboard which contains the information about total revenue earned, total bookings, occupancy rate, and present day's total check-ins and check-outs.
  It also contains the booking list.

Architecture:
  We have Used a Client-Server Architecture, Where the Admin adjusts the Price Increase multiple and the System adapts based on the values provided

Tech-Stack:
  Frontend - HTML/CSS/JS
  Backend - Django/Python
  Database - PostgreSQL
  Deployment - Vercel
